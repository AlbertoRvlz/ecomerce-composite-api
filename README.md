# E-Commerce Composite API & Dashboard

Proyecto de implementación de un Composite API (API Agregadora) en Java y Spring Boot.

## Requisitos
- Java 21 o superior
- Maven 3.x

## Estructura del Proyecto
- Microservicio 1: Catálogo de Productos
- Microservicio 2: Inventario y Almacén
- API Externa: Tipo de Cambio / Divisas (Frankfurter API)
- API Agregadora: Composite API (/api/v1/product-summary/{id})
